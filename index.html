How it works

From GitHub org to live dashboard in three steps

1

Connect the org

Point DashView at the ArtivoraLabs org with a scoped GitHub token — no app install, no webhook setup.

2

Auto-sync projects & repos

Every project and repository the token can see is pulled in automatically, and re-synced every 5 minutes.

3

Track everything in one place

Progress, task status and repo activity render as live charts and cards — click through to GitHub anytime.
