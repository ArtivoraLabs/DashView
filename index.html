Security

It can read your Odoo. It can't change it.

Your data stays in Odoo. DashView only reads what the connected user is allowed to see.

Read-only access

Connect with a dedicated Odoo user that has no write rights.

Allow-listed hosts

Requests go only to the Odoo hosts and models you approve.

Roles for your team

Owners and admins add members. Sign-in lasts for the browser tab.

Audit and limits

AI requests are logged and rate limited on the server.

FAQ

Before you connect.

Can DashView change data in Odoo?+

No. Connect it with a read-only Odoo user and it can only read.

Do I need an API key for the AI Assistant?+

No. It works locally by default. You can choose a hosted provider in Settings if you want one.

Where does Data Studio keep my files?+

On your device. Imported files are not uploaded by Data Studio.

Can I use it on my phone?+

Yes. The site is responsive and can be installed as an app.
