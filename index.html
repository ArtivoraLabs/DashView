05 — Process

Live in three steps

STEP / 01

Set your token

Add your GitHub token with read:project and repo scope to .env. No webhooks, no OAuth app, no extra setup.

STEP / 02

Start the server

Run npm start. The server pulls live data from the GitHub GraphQL API and caches it for instant dashboard loads.

STEP / 03

Open the dashboard

Navigate to the dashboard, hit ⌘K to search, and see every project and repo in the org — updating automatically every 5 minutes.

06 — Trust

Built to sit inside a real organization

DashView is self-hosted and open source, so your organization's data never leaves infrastructure you control.

Server-side tokens

Your GitHub token lives in the server's environment only — it is never sent to, or exposed in, the browser.

Read-only scopes

DashView only ever requests read access to projects and repositories. It cannot modify anything in your org.

Self-hosted

Run the API on your own infrastructure — Render, Railway, Fly.io, or a private VPS. Nothing routes through a third party.

Open source

Every line of the server and client is auditable on GitHub, so your team can verify exactly what DashView does.

07 — Questions

Before you connect it

The things most engineering leads ask before rolling DashView out to the team.

Does DashView ever get write access to our GitHub org?+
No. The token you provide only needs read:project and repo read scopes. DashView cannot create, edit or delete anything in your org — it only reads and displays.
Where does our data actually live?+
On infrastructure you choose and control — Render, Railway, Fly.io or your own VPS. DashView is self-hosted, so nothing about your org's projects or repositories passes through a third-party service.
What happens when someone creates a new project?+
Nothing manual. Any project or repository your token can see appears on the dashboard automatically on the next sync — there's no admin step to add it.
How fresh is the data on screen?+
Responses are cached for 60 seconds server-side, and the dashboard auto-refreshes every 5 minutes. A manual Refresh button forces an immediate re-sync whenever you need it right now.
Can we audit exactly what DashView does?+
Yes — the entire server and client codebase is open source. Nothing runs that your team can't read, line by line, before deploying it.
