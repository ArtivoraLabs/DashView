User manual

Everything you need to run DashView: connect Odoo, read the Overview, drill into data, export reports and keep the workspace secure.

Getting started

DashView is a browser app: no install or build step. Open dashboard.html (or install it from Settings → Data & backup → App & offline).

Connect Odoo in Dashboard → Settings → Odoo: enter the URL, database, user and an API key. Use a dedicated read-only Odoo user.

Without a connection the app runs in guest mode with the local AI and Data Studio.

Overview

The Overview shows live KPIs and charts from your Odoo. Pick a period with 30D / 90D / 1Y and press Refresh to reload. Use the company selector to choose one company or all companies; financial totals are not combined across mixed currencies.

The Operations & fulfilment panel includes BOMs, manufacturing orders, posted invoices, purchase orders, GRNs/receipts and deliveries. Click a metric to open the matching Odoo records; access failures for one model do not hide other metrics.

Hover any bar, slice or line point for exact values; other bars dim so you can focus. Bar charts with 12 or fewer bars show value labels.

Click a KPI card to open its detail panel: current vs previous, change, definition and 12-month trend.

Export a CSV or a full PDF report from the Export menu.

Drill-in

Click a chart bar, slice, point, Overview KPI or Operations metric to open the Drill Explorer.

Use its breakdown tabs and breadcrumb trail to filter by company, date, customer, product or status, then select Records to see matching Odoo documents. Search applies on the server to the current selection; Previous/Next loads 25 records at a time. Each document can open directly in Odoo.

Export CSV exports all matching records (up to 10,000); narrow the search if a larger result is capped. Company and drill filters stay in effect throughout navigation and export. Press Esc to close the explorer.

Data Studio

Import CSV or Excel files, review column types, clean data, build charts, pivots and hierarchy drill-downs.

Everything runs in your browser; files are never uploaded.

Reports and export

PDF reports contain a cover, contents page, KPIs, insights, charts, data table and pivot, with page numbers and a confidentiality footer. Long tables are capped; the Excel export always has the full data.

Excel reports include Summary, Data, Pivot and Charts sheets with formatted headers and number formats.

AI Assistant

Works locally with no key. Optionally choose a hosted provider in Settings → AI Assistant.

Ask about your Odoo data (aging, comparisons, concentration, pipeline, low stock) or paste code to debug.

Open the context disclosure to see exactly what a hosted request may include.

Settings

Configure appearance, theme, Liquid Glass surface, accessibility, dashboard preferences, Odoo, AI, security, install/offline support, privacy, backups and updates in the main Dashboard → Settings workspace.

Help & manual contains this guide and keyboard shortcuts. The app version opens release history; Reset preferences resets appearance and workspace preferences without removing Odoo connections, workbooks or reports.

Press / to search settings.

Security

Turn on a passcode: it encrypts your stored API key and locks the workspace after inactivity (auto-lock). Lock instantly with Ctrl+Shift+L.

After 5 wrong passcodes the app locks out with increasing delays.

The Security checkup gives an A–F grade and tells you what to fix. Keep Exclude secrets from backups on.

Software updates

A banner appears when a new version exists. Choose Download, then Install & Restart. Nothing installs without your tap.

The update sheet lists size, release date and what’s new tagged New / Fixed / Improved. Click the version in Settings to review the release history. Remind me tomorrow postpones non-critical updates.

Keyboard shortcuts

Ctrl+, open settings · / search settings · Ctrl+Shift+L lock · Esc close the Drill Explorer or a sheet.

Troubleshooting

Charts empty: check the Odoo connection status at the top of the Overview, then Refresh.

An operations metric is unavailable: check the connected Odoo user’s access to that model; each metric reports access problems independently.

Update not appearing: Settings → Updates → Check for updates; the app must be served over HTTPS.

Forgot passcode: it cannot be recovered. Remove the app data in your browser and reconnect Odoo.

Slow charts: turn off Chart animations and use Compact density.
