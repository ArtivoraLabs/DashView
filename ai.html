This runs on the real Claude API - add your key in Settings to get started.

The AI can make mistakes. Your key/token stays in this browser and is only ever sent to the provider you chose in Settings.

Connect an AI provider

Use your own Anthropic key, or your GitHub token via GitHub Models - either way, calls go straight from your browser to the provider.

Create a token at github.com/settings/tokens with the models scope (classic token) or models: read permission (fine-grained token). Calls go to models.github.ai, GitHub's own free inference API - no Anthropic key needed.

Get a key at console.anthropic.com. Stored only in this browser's localStorage. Because this is a static site, the key is visible in your browser's network requests - don't paste a key with billing you're not comfortable exposing on a device you don't control.
