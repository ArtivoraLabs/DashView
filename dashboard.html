Account & login

Choose how sign-in works for this dashboard

Simple (built-in)
Off (default): a local admin account that you create the first time you sign in. There is no default password — the password you choose is stored only as a salted hash on this device, repeated wrong attempts lock sign-in for a while, and the session ends after 30 idle minutes. It is a convenience gate for a static site, not protection against someone who controls this browser; use the accounts backend for real multi-user security. Forgot it? Clear this site’s data in your browser to set up a new admin account.
On: real sign-up/sign-in against your deployed DashView API. Requires wrangler d1 create, running the migration, and setting the JWT_SECRET/ODOO_ENC_KEY secrets (see worker-src/README.md).

3-step setup

Takes about 5 minutes — no servers, no code

1
Create an Odoo API key

In Odoo: Settings → Users → your account → Account Security → New API Key. Use this key here — not your login password.

2
Deploy the Cloudflare Worker (free, 2 min)

Go to workers.cloudflare.com → free account (no credit card) → Create Worker → paste the full contents of cloudflare-worker.js → Deploy → copy the Worker URL (e.g. https://dashview-proxy.yourname.workers.dev).

3
Fill the fields above and connect

Enter your Odoo URL, database, username and API key; sign in to DashView to use its authenticated Node API, or add the read-only Worker URL for the Odoo Live explorer → click Connect to Odoo. Task assignments and Team use authenticated Node API reads and task writes.

Security checkup

Live assessment of how well this workspace is protected

–

    Passcode & encrypted credentials

    Locks the workspace and encrypts your Odoo API key on this device (AES-256-GCM, PBKDF2 key)

    Passcode off

    Secure storage needs HTTPS (or localhost). Open the app over HTTPS to enable a passcode.

    A 12+ character passcode is required before saving Odoo API keys. Keys are encrypted on this device and cleared from memory when the workspace locks.

    There is no recovery: if you forget the passcode, use “Wipe all local data” below and reconnect Odoo. Brute-force attempts are rate-limited (5 tries, then increasing delays).

    Lock down your Cloudflare Worker

    The proxy forwards your API key — restrict who can use it

    In Cloudflare → your Worker → Settings → Variables, add these two values. Then run any Odoo request here — the checkup above verifies the origin lock automatically.
